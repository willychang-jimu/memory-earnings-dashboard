# 記憶體三雄供貨追蹤

追蹤 **三星 Samsung、美光 Micron、SK 海力士 SK Hynix** 從 2026 年起每一季法說會上
對**供給與供貨**的說法，做成可以橫向比對的靜態 dashboard。

**核心問題**：這三家供應商的貨到底夠不夠、什麼時候會鬆？
所以主視圖是供給面——擴產動作、位元出貨成長（bit growth）、供需鬆緊、報價方向、
售罄狀態與長約（LTA）。財務數字是輔助佐證（capex 增加可以佐證擴產說法），
放在獨立分頁備查，不是主角。

## 線上版

**<https://willychang-jimu.github.io/memory-earnings-dashboard/>**

（GitHub Pages，push 到 `main` 後約一分鐘自動更新。手機可加到主畫面當捷徑。）

## 本機開發

```bash
python3 -m http.server 8765
```

然後開 <http://localhost:8765/dashboard/index.html>。

> **注意**：不能直接用 `file://` 雙擊開啟 `index.html`。
> 頁面用 `fetch()` 讀 `data/*.json`，瀏覽器的 CORS 政策會擋掉 `file://` 的請求，
> 畫面會一片空白。一定要透過 HTTP 伺服器（本機用上面那行，線上用 GitHub Pages）。

## 怎麼用

- **各季度**：逐季、逐家的完整內容（供需狀態、報價、位元出貨、擴產、售罄／長約、
  管理層發言、次季展望、關鍵財務、出處），一季一段、一家一張卡片。
  **最新一季預設展開，較舊的季度收折起來**，點季度左邊的箭頭展開。
  每季標題列有「整季選入簡報」，可以一次勾選那一季的三家。
- **跨季比較**：要比較不同季度變化時看這裡——圖表、供需時間軸、供給對照矩陣、
  報價方向、擴產時間軸，以及依主題彙整的管理層說法。
- **匯出簡報**：每個區塊右上角有勾選框，勾好要的內容（圖表也可以勾），
  按右下角「生成 PowerPoint」就會下載 .pptx。
  **圖表匯出成 PowerPoint 原生圖表**（向量、可縮放、可直接改顏色與標題，不是截圖），
  表格也是可直接編輯的原生表格。內容過長會自動分頁，每頁都帶標題與頁碼；
  投影片上的文字會裁到可掃視的長度，完整內容仍留在 dashboard。
  > 產生期間請讓分頁保持在前景——瀏覽器在背景分頁會暫停壓縮工作，看起來像卡住。

## 專案結構

```
data/
  samsung/2026Q1.json ...      三星逐季（日曆季）
  micron/FY2026Q1.json ...     美光逐季（財年季，檔名用 FY）
  sk_hynix/2026Q1.json ...     SK 海力士逐季（日曆季）
  broker_reports/YYYY-MM-DD_<bank>_<company>.json   投行觀點，一則一檔
  manifest.json                前端的入口索引（由腳本產生，不要手改）
  SCHEMA.md                    欄位規格
dashboard/
  index.html / app.js / style.css
scripts/
  build_manifest.py            掃描 data/ 重建 manifest.json
  normalize.py                 把各來源的原始結構正規化成前端吃的扁平欄位
```

## 每季更新流程

1. 把新一季的 JSON 放進對應公司資料夾（欄位照 `data/SCHEMA.md`）。
2. `python3 scripts/normalize.py` — 正規化欄位、補上口徑標記（冪等，可重複執行）。
3. `python3 scripts/build_manifest.py` — 重建索引。
4. 更新 `data/analysis/upcoming.json`（把已公布的那筆換成下一季）與
   `data/analysis/divergences.json`（檢查新一季有沒有新的矛盾、舊的是否已失效）。
5. 若動到 `dashboard/app.js` 或 `style.css`，記得同步更新 `index.html` 裡的
   `?v=YYYYMMDD` 版本參數，否則瀏覽器會載到舊版。
6. 重新整理頁面確認。

下一批資料的時間點會顯示在「供給與供需」分頁最上方（含倒數天數）。

## 讀這個 dashboard 之前必須知道的三件事

這三點不是免責聲明，是**看懂圖表的前提**：

1. **三家的「口徑」不同，不是對等比較。**
   三星**沒有**單獨揭露記憶體事業的財務數字，本專案採用其 **DS 部門**
   （記憶體＋System LSI＋晶圓代工）數字；SK 海力士與美光則是**公司整體**。
   所以「三星營收比較高」不代表它的記憶體業務比較大。

2. **財報週期不同。** 美光是財年制（財年結束在 8 月底／9 月初），它的
   「FY2026 Q1」實際涵蓋的是 2025 年 9–11 月。跨公司比較時一律換算成
   **對應日曆季**（以財報期間結束月份歸屬），圖表的 X 軸用的是日曆季。

3. **幣別不同，所以絕對金額不畫在同一張圖。**
   美光是美元、三星與海力士是韓元。跨公司的營收趨勢用「各家首季 = 100」的
   指數圖比較成長斜率；絕對金額則拆成三張各自比例尺的小圖。
   百分比（毛利率、營益率、漲跌幅）是共同單位，才會畫在同一軸上。

## 資料來源與限制

- **財務數字**：三家公司官方 IR 揭露，以及路透、CNBC、PR Newswire、TrendForce 等
  公開財經媒體報導。每一筆都在 `sources` 附出處連結，dashboard 的「原始資料」
  分頁可以逐筆點開查證。
- **投行觀點**：大摩／小摩等機構的研究報告全文是付費／內部流通，**本專案沒有**
  也不會收錄報告全文。這裡呈現的是**公開新聞已經轉述的**評等、目標價與一兩句
  論點摘要，並附上該則新聞的連結。覆蓋度受限於公開報導多寡——例如 UBS、
  美銀對兩家韓廠的看法就幾乎找不到免費英文報導。
- **查不到就留空**。所有 `null` 欄位在畫面上顯示「—」，不用估計值填補；
  資料本身的信心程度（例如「這個數字是第三方換算」「這是回推得出的」）
  記在各筆的 `notes`，畫面上可以展開閱讀。
- **供給面說法是「管理層自己講的」**，不是第三方查核過的事實。公司對自家供給
  偏樂觀或偏保守都有動機，這個 dashboard 的用途是把三家的說法並排，
  讓**彼此矛盾的地方浮出來**，不是把任何一家的說法當成客觀現實。
